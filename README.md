# Krypto-Notebooks · HEID TECH Heidenheim

Python-Notebooks zur Unterrichtsreihe Verschlüsselung (Fachinformatiker Systemintegration, LF 11b).
Alles läuft im Browser, installieren musst du nichts.

**So geht's**

1. Links in der Dateiliste den Ordner des Blocks öffnen, z. B. **Block2**.
2. Das Notebook per Doppelklick öffnen.
3. Zelle anklicken, **Umschalt + Enter** führt sie aus. Arbeite von oben nach unten.
4. Antworten gehören auf dein Aufgabenblatt. Das Notebook speichert nur in diesem Browser.

Verwende ein normales Browserfenster, kein privates.
